# Analysis of Top Tech Companies 📊💻

This project presents an in-depth analysis of top tech companies using **Python** for data processing and **Tableau** for interactive visualizations and forecasting. The goal of this analysis is to uncover trends, compare company performance, and forecast future growth based on historical data.

## 🔍 Project Overview

This project involves:

- Collecting and preprocessing data of leading tech companies
- Performing Exploratory Data Analysis (EDA) using Python (Pandas, Matplotlib, Seaborn)
- Creating insightful dashboards using Tableau
- Implementing forecasting models in Tableau to visualize projected company growth
- ## 🧠 Tools & Technologies

- **Python**: Data cleaning and exploratory data analysis
  - Libraries: `Pandas`, `NumPy`, `Matplotlib`, `Seaborn`
- **Tableau**: Visualization, Dashboarding, and Forecasting
- **Excel/CSV**: Data sourcing and pre-processing

## 📊 Tableau Dashboard

The interactive dashboard visualizes key performance indicators like:

- Market Capitalization
- Revenue Growth
- Net Profit Margins
- Stock Price Trends
- Future Forecasting using built-in Tableau tools


## 📈 Forecasting

Time-series forecasting is applied to project trends for:

- Stock Prices
- Revenue or Net Income
- Market Cap Growth

This helps in identifying potential future leaders in the tech space.

## ✅ Key Takeaways

- Tableau provides strong capabilities for business-level storytelling through visuals.
- Forecasting in Tableau gives a quick look at future trends using historical data patterns.
- Python is excellent for preprocessing and EDA, ensuring high-quality input for Tableau.
